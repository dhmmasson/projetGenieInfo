## Feature description

Transform the image with a mirror effect: vertical symmetry.


Parameters|value
-|-
name         | mirror_vertical
Command | `-c mirror_vertical`
Input          | an image 
output       | a new image `image_out.bmp` that is a vertical symmetry of the input image

## Usage

```bash
./freud.exe -f images/input/image.jpeg -c mirror_vertical
```
## Output

A new image `image_out.bmp` that is a vertical symmetry of the input image
